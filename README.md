# 🎂 Cake Shop Website

A simple and responsive Cake Shop Website built using HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- Browse cakes
- Add to cart
- Admin panel
- Responsive design
- Order management

## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Run Locally
1. Clone the repository
2. Move project to `htdocs` (XAMPP)
3. Import database in phpMyAdmin
4. Start Apache & MySQL
5. Open `http://localhost/project-folder-name`
